# Cross-platform clinic controls

Administrators can request branding changes (display name, service segment, welcome text, primary and accent colours) and clinician invitations through the admin portal. iOS, Android, and web mobile clients route users into patient or clinician sign-in paths.

All identity, clinic membership, branding changes, and invitation delivery must be performed by the authenticated server with audit logging. The interfaces do not persist data until the tenant repository and Supabase administration integration are configured.
